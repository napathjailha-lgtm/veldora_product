# Veldara 2D starter art

This branch begins the switch from procedural 3D meshes to a 2D, 3/4-view RPG presentation inspired by classic isometric MMORPGs. The SVGs in this folder are original temporary pixel-style vector sprites created for this prototype; they are not ripped from Ragnarok Online.

## Free CC0 art packs for expansion

- **Kenney Roguelike/RPG Pack** — 1,700 16×16 tiles for terrain, buildings, interiors, props and UI. CC0: https://kenney.nl/assets/roguelike-rpg-pack
- **Kenney Tiny Town** — 130 16×16 town tiles including houses, trees, fences and paths. CC0: https://kenney.nl/assets/tiny-town
- **Kenney Roguelike Characters** — character parts, adventurers and monsters; front-facing components, not complete walk cycles. CC0: https://kenney.nl/assets/roguelike-characters
- **FreeRPG pixel project by OLTEANU** — a small character sprite sheet, ground tile and enemy; CC0: https://ochiogrande.itch.io/free-rpg-pixel-project-by-olteanu

Kenney's packs are CC0/public-domain equivalent, including commercial use; attribution is optional. These source links are recorded for transparent asset provenance. The first 2D scene currently uses the original SVG art in this repository so it can load without external downloads.

## Current scope

The new scene is a local visual/gameplay prototype: 2D movement, a following fire partner, nearby wild monsters, auto battle, skill hit effects and a compact HUD. Multiplayer, save migration, full evolution UI and quests have not yet been ported to this new scene; the previous online 3D prototype scripts remain in the repository for reference. No deployment is performed from this branch.
